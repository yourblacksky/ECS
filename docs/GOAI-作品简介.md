# GOAI 作品简介

以下正文可直接用于参赛提交，控制在 500 字以内。

## 提交正文

ECS 是本地优先的 Agent 可信执行内核，面向需要审批和结果追踪的会议督办。它把理解与表达交给模型，把能力选择、参数校验、权限、状态、幂等、回执、补偿和审计交给确定性系统，让小模型和边缘设备参与可控协作。

在主场景中，AgentTeams 负责角色编排、任务拆解、上下文传递和状态追踪；ECS 将任务映射为 Office Stage，通过 Skill 与 Connector Tool 执行。会议材料依次经过事实提取、责任核验、人工批准、动作派发和回执验证。责任人或期限缺失时，流程在外部动作前阻断；结果未知时进入 recovery_required，不伪装成功。

当前实现包含 Tool、Skill、Agent、Pipeline、Office 分层，提供关系授权、Session、Trace、Metrics、Attempt、Lease 与 Outbox，覆盖多平台。仓库留存双路径五轮回归、三节点演示和可复现的 AgentTeams 补丁。办公 Connector 为本地演示实现；组织系统、TLS/mTLS 与外部 Tool 沙箱属于生产化边界。

## 使用边界

- 正文描述的是当前仓库可以验证的实现，不代表已经接入真实组织系统。
- 参考运行证据使用固定合成输入，不是真实用户或客户案例。
- 移动端是否使用本地模型取决于显式模型配置；“本地优先”不表示所有默认配置都离线运行。
