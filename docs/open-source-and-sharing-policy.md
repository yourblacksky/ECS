# ECS 开源与分享规则

ECS 采用 [Apache License 2.0](../LICENSE) 发布。任何人都可以在该许可证范围内使用、修改和
分发项目；第三方组件继续遵循各自许可证，详见
[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

## 可以公开分享的内容

- 已提交到公开仓库的源码、文档、脱敏演示资产和正式 Release；
- 自行构建且保留许可证、NOTICE 与第三方声明的二进制或修改版本；
- 不包含真实凭证、内部地址、个人数据和未获授权素材的产品截图与运行证据。

## 不应进入公开仓库的内容

- API Key、token、签名材料、构建凭证或含凭证的安装包；
- 真实用户数据、私人会话、本机绝对路径和未经同意的个人身份信息；
- 内部评审记录、答辩备忘、未公开部署配置和受 NDA 约束的材料；
- 许可证不允许再分发的模型权重、字体、图片、视频或第三方代码。

## 发布前检查

1. 对完整 Git 历史和当前变更执行密钥与个人信息扫描；
2. 确认移动端和交付包不嵌入模型 API Key；
3. 核对 `THIRD_PARTY_NOTICES.md`、`NOTICE` 和随附许可证；
4. 运行测试、交付包检查与可复现演示；
5. 发现凭证泄漏时先撤销和轮换，再清理历史，不能只删除文件。

Apache-2.0 不授予第三方商标、数据、模型或内容的额外权利，也不替代部署者的数据保护、
出口管制或其他法定义务。
