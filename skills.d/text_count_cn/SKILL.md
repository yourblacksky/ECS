# text_count_cn

统计一段中文文本的字符构成：汉字、字母、数字、标点、空白各多少个。

## 何时使用

周报字数检查、"这段话有多少个汉字"等统计需求。

## 输入 / 输出

- 输入：`{"text": "原文"}`
- 输出：各项计数 + `summary`（可直接照念的中文结论）

## 风险

低。只读输入文本，不修改。
