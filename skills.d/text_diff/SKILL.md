# text_diff

对比两版文本的差异，报告新增、删除和未改动的行。

## 何时使用

"这两版方案哪里不一样"、合同修订对比等场景。

## 输入 / 输出

- 输入：`{"text_a": "旧版", "text_b": "新版"}`
- 输出：`added` / `removed` / `unchanged` 行数 + `diff` 明细 + `summary`（可直接照念的中文结论）

## 边界

按行对比；同一行内的逐字改动会以"删一行加一行"呈现。

## 风险

低。只读输入文本。
