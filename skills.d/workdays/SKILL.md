# workdays

计算两个日期之间的工作日天数（周一至周五，含首尾两天）。

## 何时使用

用户问"X 月 X 日到 X 月 X 日有几个工作日"等排期、请假问题时使用。

## 输入 / 输出

- 输入：`{"start": "YYYY-MM-DD", "end": "YYYY-MM-DD"}`
- 输出：`{"workdays": n, "weekend_days": n, "total_days": n}`

## 边界

只按周一至周五计算，**不考虑法定节假日和调休**。涉及节假日精确结果时应说明这一限制。

## 风险

低。纯本地确定性计算。
